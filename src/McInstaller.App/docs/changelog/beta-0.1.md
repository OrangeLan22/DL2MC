# beta 0.1

首个可用版本。

## 原版游戏

- 支持正式版、快照、远古版本的下载与安装
- 官方源与 BMCLAPI 镜像双通道，测速低于阈值时自动切换镜像

## 加载器

- 支持 **Fabric**、**Fabric API**、**Forge**、**NeoForge**、**OptiFine** 
- 加载器之间的冲突检测

## 版本管理

- 扫描并列出启动器已有的全部版本，显示其加载器构成
- 重命名：同步改写版本 JSON 内的 id 与依赖它的 inheritsFrom
- 切换加载器版本：原有 mods / config / saves 自动迁移到新版本目录

## 界面

- 亮色、暗色、跟随系统三套主题
