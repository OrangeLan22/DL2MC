# beta 0.2

## 原版游戏

- SHA1 校验、断点续传、失败自动重试
- 进度窗口实时显示总进度、分项进度、下载速度与当前文件

## 加载器

- 自动探测适配版本，也可手动指定任意历史版本
- Forge / NeoForge 调用官方 installer；旧版本 Forge 自动改用 install_profile 手工安装
- NeoForge 依赖预下载，避开官方超时问题
- OptiFine 自研安装逻辑

## 版本管理

- 删除：存在子版本依赖时阻止并列出依赖者，避免删出无法启动的版本
- 安装或更新失败时自动回滚本次新建的版本目录

## 界面

- 左侧列表宽度、日志区高度可拖拽调节，尺寸写入配置
- 版本搜索框实时过滤，与正式版/快照/远古筛选叠加生效
- 日志面板支持全选与复制，便于贴出求助
- 安装过程中的下载窗口可最小化到状态栏，右下角点击可恢复
- 设置项覆盖下载源、并发数、重试次数、慢速阈值、主题、日志开关等

## 其他

- 提供命令行子程序，便于单独调试原版安装与各加载器
