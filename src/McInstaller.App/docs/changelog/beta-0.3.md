# beta 0.3

## 新增

- 更新检查：启动时自动查询 GitHub，发现新版本弹窗提示并提供下载入口
- 设置界面显示当前版本号，可手动检查更新
- 新增「常见问题」文档，覆盖目录选择、镜像、加载器安装、故障排查
- 新增更新日志页面，按版本倒序展示历史说明

## 改进

- 启动器目录校验改为探测 `.minecraft` 子目录，不再依赖特定启动器
- 加载器安装失败时自动回滚本次创建的版本目录
- 安装进度窗口支持最小化到状态栏，点击可恢复

## 修复

- 修复资源路径与程序集名不一致导致文档页面崩溃的问题
- 修复主题切换选项无法保存、输入框清空时报转换异常的问题
- 修复 NeoForge 依赖直连官方源超时的问题，改为预下载
- 修复老版本 OptiFine 安装失败，1.8 及更早版本自动改用 mod 方式
- 修复进度条流光覆盖不全的问题

## 说明

- 本版本不包含自动更新，仍为手动下载替换
