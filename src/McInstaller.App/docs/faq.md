# 常见问题

### 程序会不会有病毒或后门？

你的安全意识值得表扬，但这是开源项目，你可以自己检查源码。

## 目录与启动器

### 为什么必须先选 .minecraft 文件夹？

所有下载内容都写进你选的那个目录，本程序不复制、不搬运。选错目录会出现「装完了但启动器里没有」的情况。

通常在启动器的安装根目录下就能找到这个文件夹。

### 装完回启动器看不到新版本？

在启动器里手动点一次「刷新版本列表」。

### 为什么会安装多个版本？

出现这种情况通常是因为你选择了加载器，版本列表里会出现这个版本的原版和带加载器的版本。

多出的原版是父版本，再次安装同样版本的游戏会直接继承而不会重新下载，这不会影响正常游戏和多余的磁盘占用，**但删除父版本后子版本会无法启动**

## 下载

### 下载卡住了怎么办？

如果长时间没有进度更新，日志也没有新的打印内容，很可能是发生了互锁，请尝试重新安装。

这个已知问题将在未来版本修复。

### 下载很慢怎么办？

设置里有两个与镜像有关的开关：

- **镜像加速**：允许使用 BMCLAPI 镜像作为备用通道
- **慢速自动切换**：官方源实测速度低于阈值时自动切到镜像

默认都开着。如果仍然很慢，把「慢速阈值」调大一些，让切换更早触发。

或者你的网本身就不好。

## 加载器

### 安装 OptiFine 时提示走 mod 方式？

1.8 及更早版本的 OptiFine 是「补丁式」安装器，本程序暂不处理这种机制。

这个已知问题将在未来版本更新。

### 可以同时装多个加载器吗？

可以，但有冲突限制。互斥的组合会被置灰，无法勾选。

### 换了加载器版本，原来的存档和 mod 会丢吗？

不会。会自动从旧版本目录迁移到新目录，日志里会列出迁移了哪些内容。

## 出错与排查

### 安装失败了怎么办？

1. 点结果提示里的「复制日志」，看具体报错
2. 失败的版本目录会自动回滚，不会留下半成品
3. 常见原因：网络中断、Java 版本不符、磁盘空间不足

### 提示找不到 Java？

Forge / NeoForge 的安装需要 Java。程序会自动探测：

- JAVA_HOME 环境变量
- PATH 里的 java
- Program Files 下的常见 JDK 目录

都找不到时会明确提示版本要求（比如「该游戏版本要求 Java 21+」）。按提示装对应版本即可。

未来版本可能会添加JAVA下载的自动化。

### 日志一直在刷，看着很乱？

设置里可以关闭「网络日志」，默认只保留关键信息。

### 中途取消会留下垃圾文件吗？

不会。取消时会回滚本次新建的版本目录。

共享的 libraries、assets 不会删除——它们是多个版本共用的，删掉会影响其他版本。

## 其他

### 这个程序会启动游戏吗？

不会。它只负责下载和安装，启动游戏仍然用你原来的启动器。

### 支持哪些系统？

目前只在 Windows 上实测过。代码层面用了跨平台的框架，但 Linux / macOS 未经验证，因为我懒得装虚拟机且这俩平台的用户相对较少。

### 会收集我的信息吗？

不会，且永远都不会。没有任何统计、上报或账号体系，所有网络请求只发往 Mojang、BMCLAPI、Fabric、NeoForge、Modrinth 这些下载源。
